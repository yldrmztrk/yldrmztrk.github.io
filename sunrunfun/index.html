Sun Run Fun

Tek dokunuşla uçurtmana tutun, Türkiye şehirlerinin üstünde uç!

Ayçiçeği şapkalı minik kahramanımız, uçurtmasıyla gün batımında şehirlerin üstünde süzülüyor. Ekrana dokun, yüksel; bırak, alçal. Binaların arasından geç, martıların taşıdığı simitleri kap, şehrinde birinci ol.

  • İstanbul
  • Ankara
  • İzmir
  • Antalya
  • Nevşehir (Kapadokya)
  • Trabzon

Her ay yeni şehirler geliyor. Reklam yok, satın alma yok, hesap yok.

iPhone'una kur

Oyun şu an deneme sürümünde. Apple'ın TestFlight uygulamasıyla ücretsiz kurabilirsin:

  1. iPhone'unda App Store'dan TestFlight uygulamasını indir (Apple'ın kendi uygulaması, ücretsiz).
  2. Aşağıdaki düğmeye dokun.
  3. TestFlight açılınca Kabul Et, sonra Yükle'ye bas.
  4. Sun Run Fun ana ekranına gelir. Hadi uç! 🌻
